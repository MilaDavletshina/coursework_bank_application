# Сoursework_bank_application
## Курсовая работа
## Проект 1. Приложение для анализа банковских операций 
## Описание
Приложение для анализа банковских операций состоит из:
1. Веб-страницы:
   - Главная
2. Сервисы:
   - Поиск переводов физическим лицам
3. Отчеты:
   - Траты по категории

За основу берутся личные данные с сайта Т-Банк, в период с 01.01.2024 по 31.05.2024
