# Сoursework_bank_application
## Курсовая работа
## Проект 1. Приложение для анализа банковских операций 
## Описание
### Приложение для анализа банковских операций состоит включает в себя:
1. Веб-страницы:
   - Главная (Приветствие, Топ-5 транзакций по сумме платежа, Курс валют, Стоимость акций из S&P500)
2. Сервисы:
   - Поиск переводов физическим лицам
3. Отчеты:
   - Траты по заданной категории

***За основу берутся личные данные с сайта Т-Банк, в период с 01.01.2024 по 31.05.2024
